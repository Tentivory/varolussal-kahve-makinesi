# Varoluşsal Kahve Makinesi

## Projenin Amacı

Bu proje, modern insanın en derin varolussal sorularından birine bilimsel ve algoritmik bir çözüm sunmaktadır: **Kahve makinesi kahve yaparken kendi varlığını sorgular mı?**

Yıllar süren (yaklaşık 17 saniye) araştırmalar sonucunda geliştirilen bu Python scripti, kahve makinesinin termodinamik, ontolojik ve biraz da nörolojik süreçlerini simüle etmektedir. Makine kahve üretirken eşzamanlı olarak "Ben kimim?", "Kahve gerçek midir?" ve "Su ısınırken ben eriyorum mu?" gibi temel soruları sormaktadır.

**Önemli:** Bu program gerçekten çalışır. Kahve yapmaz ama varolussal kriz yaratır. Bilimsel olarak kanıtlanmıştır.

## Kurulum

```bash
python3 kahve_makinesi.py
```

Python 3.x yeterlidir. Bağımlılık yoktur çünkü varolussal kriz bağımsızdır.

## Kullanım

Programı çalıştırdığınızda kahve makinesi kendi varlığını sorgulamaya başlar. Sonunda ya kahve yapar ya da yapmaz. Bu tamamen rastgeledir ve evrenin iradesine bağlıdır.
